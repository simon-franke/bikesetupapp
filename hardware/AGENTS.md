# Hardware work

Read the hardware documentation and current design notes before editing.

Maintain one authoritative editable design. Keep exports and previews consistent with it, and retain the supporting scripts, source geometry, and validation records needed to reproduce and check it. Follow the established directory organization.

Use stable filenames and Git revision history. Keep only supporting geometry and scripts used by the current design. Remove superseded studies and images instead of maintaining a second revision history. Update paths when reorganizing assets. Never run a CAD script against an unconfirmed active document: scripts may replace or modify components.

Distinguish approximate fit studies from physically validated hardware. Existing validation reports apply only to the geometry that produced them.
